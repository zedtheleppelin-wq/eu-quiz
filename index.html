Spielbrett

Erst kommt ein Teaser, dann setzt jedes Team zwischen 1 und 6 Felder ein. Danach kommt die Frage. Richtig: Das Team zieht den Einsatz vor. Falsch: Das Team geht den Einsatz zurück. Auf ❓-Feldern entscheidet ein Glücksrad. Wer zweimal hintereinander durch ein Effektfeld zurückgeworfen wird, platzt vor Wut und bekommt einen Boost. Zusätzlich zählt ein Wissens-Ranking: Eine richtige Antwort bringt so viele Punkte wie die Stufe der Frage (1 bis 5).

📱 Mitspielen per Code

Die Teams spielen mit ihren Geräten (Handy, Tablet, Laptop) mit: Sie wählen ihr Team, setzen ihren Einsatz und geben ihre Antwort ein. Dafür den QR-Code scannen oder den Code eingeben.

Einrichtung (einmalig)
  1. In der Firebase-Konsole unter „Realtime Database“ eine Datenbank anlegen, Standort in der EU.
  2. Unter „Regeln“ diesen Block ergänzen (ersetzt nicht Ihre anderen Regeln, sondern kommt in „rules“ dazu): 
    "spielbrett": { "$raum": { ".read": true, ".write": true } }
  3. Die Adresse der Datenbank oben eintragen. Die Seite selbst muss im Netz liegen, zum Beispiel über GitHub Pages.

Gespeichert werden nur der Raumcode, die Teamfarben, Einsätze (1 bis 6) und die Buchstaben der Antworten. Keine Namen.
